# 🔧 Административная панель управления курсами

## 🔐 Безопасный доступ

Административная панель доступна по защищенному URL:

```
/admin/courses/manage/3a7f8b2e9c1d4f6h8j2k5l7n9p0q
```

**⚠️ ВАЖНО:** Никому не сообщайте этот URL! Он предназначен только для администраторов.

### Быстрый доступ

На главной странице есть скрытая ссылка в правом верхнем углу логотипа УрФУ (невидимая область 20x20px). Наведите курсор на правый верхний угол логотипа для доступа.

## 🎯 Функциональность

### ➕ Добавление курса

1. Нажмите кнопку "➕ Добавить новый курс"
2. Заполните обязательные поля:
   - **Название курса** (обязательно)
   - **Кредиты** (1-10)
   - **Язык** (русский/английский) 
   - **Платформа** (УрФУ.Онлайн/НПОО)
   - **Ссылка на курс** (обязательно, должна быть валидной URL)

3. Заполните дополнительные поля:
   - **Описание** (рекомендуется)
   - **Компетенции**
   - **Интерактивный курс** (чекбокс)
   - **Категории** (выберите подходящие теги)

4. Нажмите "➕ Добавить курс"

### ✏️ Редактирование курса

1. В списке курсов нажмите кнопку "✏️" рядом с нужным курсом
2. Форма заполнится текущими данными курса
3. Внесите необходимые изменения
4. Нажмите "💾 Сохранить изменения"

### 🗑️ Удаление курса

1. В списке курсов нажмите кнопку "🗑️" рядом с курсом
2. Подтвердите удаление в диалоговом окне
3. Курс будет навсегда удален из базы данных

### 🔗 Переход к курсу

Нажмите кнопку "🔗" чтобы открыть курс в новой вкладке.

## 📋 Поля формы

### Обязательные поля

- **Название курса**: Короткое и понятное название
- **Кредиты**: Количество зачетных единиц (1-10)
- **Язык**: 
  - `ru` - Русский язык
  - `en` - English
- **Платформа**:
  - `УрФУ.Онлайн` - Платформа УрФУ
  - `НПОО` - Национальная платформа открытого образования
- **Ссылка на курс**: Полная URL ссылка на курс

### Дополнительные поля

- **Описание**: Подробное описание курса, целей и задач
- **Компетенции**: Список компетенций, которые развивает курс
- **Интерактивный курс**: Отметьте, если курс содержит интерактивные элементы

### Категории (теги)

Выберите подходящие категории для курса:

- **Ядро бакалавриата** - Базовые дисциплины
- **Математика и ИТ** - IT и математические дисциплины
- **Инженерные науки** - Технические дисциплины
- **Экономика и управление** - Экономические дисциплины
- **Гуманитарные науки** - Гуманитарные дисциплины
- **Естественные науки** - Естественнонаучные дисциплины
- **Искусственный интеллект** - ИИ и машинное обучение
- **Адаптационный модуль** - Адаптационные курсы

## 🔄 Обновление данных

- Нажмите "🔄 Обновить" для перезагрузки списка курсов
- Все изменения сохраняются в реальном времени в базе данных
- При успешных операциях появляются зеленые уведомления
- При ошибках появляются красные уведомления

## ⚡ API для разработчиков

Если вы хотите программно управлять курсами:

### Получить все курсы
```bash
curl http://localhost:3001/api/courses
```

### Добавить курс
```bash
curl -X POST http://localhost:3001/api/courses \
  -H "Content-Type: application/json" \
  -d '{"title": "Название", "credits": 3, "platform": "УрФУ.Онлайн", "link": "https://...", "language": "ru", "tags": {...}}'
```

### Обновить курс
```bash
curl -X PUT http://localhost:3001/api/courses/[ID] \
  -H "Content-Type: application/json" \
  -d '{"title": "Новое название"}'
```

### Удалить курс
```bash
curl -X DELETE http://localhost:3001/api/courses/[ID]
```

## 🛡️ Безопасность

1. **URL Защита**: Сложный URL путь защищает от случайного доступа
2. **Локальная база**: Данные хранятся локально в SQLite
3. **Нет аутентификации**: Базовая защита только через сложный URL
4. **Бэкапы**: Регулярно создавайте бэкапы файла `courses.db`

## 🚨 Важные предупреждения

- ⚠️ **Удаление необратимо**: Удаленные курсы восстановить нельзя
- ⚠️ **Нет истории изменений**: Все изменения сохраняются сразу
- ⚠️ **Валидация**: Обязательно заполняйте все требуемые поля
- ⚠️ **URL валидация**: Ссылки на курсы должны быть корректными

## 📞 Поддержка
