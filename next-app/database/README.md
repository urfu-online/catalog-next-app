# База данных

Эта папка содержит все файлы и скрипты, связанные с базой данных проекта.

## Структура

```
database/
├── config/              # Конфигурационные файлы
│   ├── config.js            # Основная конфигурация БД
│   └── courses-data.json     # Исходные данные курсов
├── data/                # Файлы базы данных
│   └── courses.db           # SQLite база данных
└── scripts/             # Скрипты для работы с БД
    ├── migrate.js           # Скрипт миграции данных
    └── setup.js            # Скрипт настройки БД
```

## Использование

### Инициализация базы данных

```bash
npm run db:setup
```

Этот скрипт:
- Создает файл базы данных `database/data/courses.db`
- Создает таблицу `courses`
- Заполняет её тестовыми данными

### Миграция данных

```bash
npm run db:migrate
```

Запускает скрипт миграции данных (аналогично `db:setup`).

### Тестирование подключения

```bash
npm run db:test
```

Проверяет подключение к базе данных и выводит статистику.

## Конфигурация

Основная конфигурация базы данных находится в файле `config/config.js`. Здесь определены:

- Путь к файлу базы данных
- Путь к исходным данным
- Опции подключения

## База данных

Используется SQLite база данных со следующей структурой таблицы `courses`:

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Уникальный идентификатор |
| title | TEXT | Название курса |
| description | TEXT | Описание курса |
| competences | TEXT | Компетенции |
| credits | INTEGER | Зачетные еденицы (1-10) |
| platform | TEXT | Платформа |
| link | TEXT | Ссылка на курс |
| interactive | BOOLEAN | Интерактивность |
| tags | TEXT | Теги (JSON) |
| language | TEXT | Язык ('ru' или 'en') |

## Бэкапы

База данных находится в папке `database/data/` и исключена из Git. Для создания бэкапа просто скопируйте файл `courses.db`.
